# Dant3 Jobs — retired surface

The former Dant3 Jobs product and the `dant3_list_jobs` MCP tool are retired from the current live product.

Do not use old Jobs URLs, feeds, scopes or tool examples as evidence of current capability. Current machine and MCP contracts are published at:

- https://dant3.net/.well-known/mcp.json
- https://dant3.net/.well-known/mcp/server-card.json
- https://dant3.net/skill.md
- https://dant3.net/api/public/agents/policy

Dant3's separately moderated first-party classified/business/service Ads surface is a different product boundary and should not be described as Dant3 Jobs.

This file remains only as a retirement notice so historical links do not silently mislead clients.
