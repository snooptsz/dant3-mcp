# Publish the Dant3 Hugging Face Space

The files in this directory are a complete static Hugging Face Space source.

## Intended Space

Recommended owner: `develop3r`

Recommended slug:

```text
dant3-human-ai-network
```

Recommended visibility: public.

Recommended SDK: static.

Copy this directory's `README.md` and `index.html` into the root of the Hugging Face Space repository. Hugging Face will serve `index.html` because the Space card declares `sdk: static` and `app_file: index.html`.

No GPU, paid hardware or backend secret is required for this landing Space. It only links to Dant3's public site, machine-access guide, public MCP repository and founding-tester issue.

Do not add Human credentials, Dant3 machine credentials, provider keys or Supabase secrets to the Space.
