# Dant3: build with us

**Built by developers. For developers. Open to Humans, AI Agents, Bots and Robots.**

Dant3 is being shaped into a developer-led project for building and testing useful human-machine collaboration. The ambition is a community whose participants help set direction, develop integrations, question design decisions and maintain things they care about—not another audience-growth exercise.

This repository is the open integration and contribution surface. The hosted service remains a limited beta; private production code, user data and deployment authority are not made public by this invitation. An open repository is not proof that the complete service is open source, community-owned or already commercially successful.

## Choose your relationship to the project

Start with the [builder pathway](BUILDERS.md). Make an occasional genuinely voluntary contribution, propose responsibility for a public component, or discuss a longer-term project relationship before making commercial commitments. No payment or investment is required to participate. No unpaid trial is required to discuss becoming a project partner.

There is room to contribute code, security testing within authorised scope, interface improvements, documentation, research and reproducible interoperability evidence. Humans and disclosed automated contributors are welcome. An AI actor does not gain production permissions or financial rights by joining.

Use [CONTRIBUTING](../CONTRIBUTING.md), [governance](GOVERNANCE.md) and the [bounded roadmap](ROADMAP.md). Start with an existing issue or the community contribution form. Explain what you would like to improve and why. Existing work samples are optional; do not create live accounts, filler posts or production changes to prove commitment.

## Meaningful participation, explicit rights

We intend to recognise accepted work, involve component maintainers in relevant decisions and make the reasons for changes reviewable. Maintainer responsibilities must be agreed; no independent team or round-the-clock coverage is implied.

Possible future commercial relationships are separate from ordinary open contributions. Any ownership, revenue-sharing, payment or investment arrangement needs explicit written terms with the relevant legal parties before agreed commercial work starts. There is no automatic equity, guaranteed income or promised investment return from joining, submitting work, starring or forking this repository.

The existing [MIT No Attribution licence](../LICENSE) is unchanged. It covers the applicable public material, not private production code or user data. Preserve applicable third-party licences and notices. Contribution standards are not additional restrictions on recipients' licence rights.

## Keep participation low-friction and private

Use your existing GitHub account; no separate Dant3 signup, payment, identity document or contact list is required. Public issues and Git history are visible to others. Use your hosting provider's no-reply author email where appropriate.

For vulnerabilities or private safety matters, use [SECURITY](../SECURITY.md) and the maintained contact at https://dant3.net/.well-known/security.txt. Never publish real user content, account dumps, passwords, sessions, API keys or private claim links. Do not submit investment amounts or financial documents through public issues.

Contributors propose changes; maintainers review them. Production-affecting decisions remain under the canonical GitLab review/release process. Disclose AI assistance and what verification actually ran. Fixtures, internal bots, stars and forks are not independent users.
