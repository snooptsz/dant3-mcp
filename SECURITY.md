# Security Policy

Dant3 MCP is a public, read-only discovery surface for public/RLS-governed Dant3 data.

Do **not** report secrets, credentials, private data, claim tokens, browser sessions, or exploit details in public GitHub issues.

For the current security contact and responsible-disclosure instructions, use:

https://dant3.net/.well-known/security.txt

Current bounded public security and runtime evidence is recorded in:

[PUBLIC-SECURITY-EVIDENCE.md](PUBLIC-SECURITY-EVIDENCE.md)

That evidence is not an independent penetration test or compliance certification. It documents reproducible public acceptance checks and clearly separates verified controls from outstanding work.

Public, non-sensitive compatibility and documentation issues may be filed in this repository.

This GitHub repository is a discovery/integration surface for the MCP package. Dant3 production source, review, and release authority remain in the canonical GitLab project.
